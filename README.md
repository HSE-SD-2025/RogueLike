# Хроники Пустоши: Аномальный Эфир (Roguelike CLI Game)

## Инструкция по запуску
1. Установите Python 3.8+ (https://www.python.org/downloads/)
2. (Рекомендуется) Создайте виртуальное окружение:
   ```
   python -m venv venv
   source venv/bin/activate  # для Linux/Mac
   venv\Scripts\activate    # для Windows
   ```
3. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```
4. Запустите игру:
   ```
   python -m roguelike.main
   ```
5. Для запуска тестов:
   ```
   pytest
   ```

## Описание
Пошаговая roguelike-игра с интерфейсом командной строки. Игрок исследует процедурно-генерируемую Зону, сражается с мутантами, избегает аномалий, собирает артефакты и снаряжение, выполняет квесты и сталкивается с перманентной смертью.

## Основные возможности
- Процедурная генерация секторов (лес, болото, завод, база)
- Несколько типов аномалий и мутантов
- Пошаговые сражения, экипировка (оружие, броня)
- Инвентарь, использование предметов (аптечка, антирад)
- Артефакты с бонусами
- Квест: найти артефакт и вернуться на базу
- Лут с мутантов
- Система сохранения/загрузки (только на базе)
- Перманентная смерть (сейв удаляется)

## Управление
- На базе: отдых, экипировка, сохранение, выход в Зону
- В секторе: движение, сбор предметов, бой, использование предметов, экипировка
- Все действия выбираются через меню (цифры и подтверждения)

## Особенности
- Сложность и случайность: каждый сектор уникален, мутанты и аномалии опасны
- Только одна жизнь: смерть = удаление сохранения
- Квесты можно выполнять многократно
